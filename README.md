# Kingdom Rush 1 模组（插件宿主 + 两个插件）

> 给《王国保卫战 1》(Kingdom Rush, Steam 版) 用的小模组。**单机自用 / 非官方**。
> 全部通过游戏自己的 `custom_script` 机制加载，**不改 exe、不改存档数据**，卸载是一键的。

---

## ✨ 现在有什么

| 插件 | 作用 |
| --- | --- |
| **kr_spec_unlimited** | **四级（专精）防御塔的技能可以一直点**，不再"只能点三次/一次"（圣骑士护盾原本只能买 1 次、特斯拉连锁只能 2 次）。每点一次照常扣金币，等级一直涨。 |
| **kr_gold_55555** | **局内一拿到金币（含进关卡的起始金币）就把金币跳到 55555**。花掉是有效的，再捡到金币又跳回 55555。 |

游戏里：**F8** 开关专精插件，**F9** 开关金币插件。

两者都由 `kr_mods.lua`（插件宿主）挂载 —— 因为游戏一次只认一个 `custom_script`，宿主负责把每帧回调转发给各个插件，所以**以后还能继续加插件**。

## 🚀 安装（3 步，小白版）

1. **下载**：本页右上角绿色 `Code` 按钮 → `Download ZIP`。
2. **解压**：把 zip 解压到任意目录（例如桌面）。**要先完整解压，不要在压缩包里双击**。
3. **双击 `一键安装.bat`**。
   - 看到 `[OK]` 和"装好了！"就成了。
   - 如果提示"找不到存档目录"：**先启动一次游戏**（进到标题界面即可），退出后再双击一次。

然后**启动游戏 → 进关卡**：金币变 55555、四级塔技能能一直点。

> 双击后被 Windows SmartScreen 拦住时：点"更多信息"→"仍要运行"。
> 杀毒软件可能对 `.bat/.ps1` 报警（因为要写存档目录）——脚本内容很短，可以直接用记事本打开看。

### 文件说明

```
一键安装.bat      ← 双击安装
检查状态.bat      ← 看装了没、日志最近几行
卸载.bat          ← 一键卸载（还原 args.lua）
install.ps1       ← 安装脚本本体（.bat 只是调它）
mods/
  kr_mods.lua            插件宿主（游戏加载的入口）
  kr_spec_unlimited.lua  插件①：四级塔专精技能无限点
  kr_gold_55555.lua      插件②：金币跳 55555
tests/                   开发者用：不开游戏的沙箱测试
```

安装做的事只有两件：把 `mods\*.lua` 复制进 `%APPDATA%\kingdom_rush\`，
并在同目录的 `args.lua` 里写一行 `"-custom_script", "kr_mods"`（原文件备份为 `args.lua.bak`）。

## 🎮 效果说明

- **专精技能**：能不能点只看游戏的 `power.max_level` 这一个数（默认 3；圣骑士护盾 1；特斯拉连锁 2；日光塔射线 4）。模组把它抬到 99，并给"按等级查表"的两处数据（日光塔射线的 `ray_y_scales`、特斯拉弹丸的 `bounces_lvl`）加了越界保护 —— 等级超过表长时取最后一档，**不会崩**。
- **数值会不会继续涨**：会。绝大多数技能都是 `基础值 + 每级增量 × 等级`（狙击的爆头率、特斯拉的连锁伤害、大贝莎的伤害/碎片、紫法石头人的血/甲/伤害、游侠的缚地数量与时长……），所以超过原上限后继续线性变强。只有上面那两张"查表"的数值到表末尾封顶（但不会崩）。菜单里的**说明文字**只有 3 条，所以第 4 级以后文案不再变 —— 数值照旧按公式算。
- **金币**：只改内存里的 `store.player_gold`，**不写存档**，退出游戏不留痕迹。

## ⚙️ 想改数值

用记事本打开 `mods\kr_gold_55555.lua`，顶部：

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `gold` | `55555` | 跳到的金币数 |
| `trigger_on_enter` | `true` | 进关卡就跳；设成 `false` = 必须自己捡到金币才跳 |
| `pin` | `false` | `true` = 每帧把金币顶回 55555（等于无限钱，买完立刻补回） |
| `hotkey` | `"f9"` | 游戏里开关 |

`mods\kr_spec_unlimited.lua` 顶部可以改 `max_level`（默认 99）和 `hotkey`（默认 `"f8"`）。
改完**再双击一次 `一键安装.bat`**（它会把新文件复制过去），然后重启游戏。

## ❓ 常见问题

**装完没反应？**
1. 先看 `kr_mods_log.txt` 有没有上面那几行：没有 = 游戏没加载模组 → 双击 `检查状态.bat` 看 `args.lua` 是否已指向 `kr_mods`。
2. 改动要**重启游戏**才生效（在关卡里装没用）。
3. 启动方式不影响：Steam 开始、桌面图标、各种启动器都行（游戏会自己读 `args.lua`）。

**新建存档栏会崩？**
这个 Steam 构建在 DEBUG 状态下新建存档栏会报 `data.slot_template_debug not found`（跟模组无关）。**测试时用已有存档栏**即可。

**`args.lua` 提示格式不认识？**
把它改名成 `args.lua.old`，再双击一次 `一键安装.bat`（会新建一个）。

**会不会影响成就 / 云存档？**
模组只改运行时内存，不写存档文件；但它确实修改了游戏逻辑（金币/技能上限），**可能影响成就与游戏体验**，请自行判断。
